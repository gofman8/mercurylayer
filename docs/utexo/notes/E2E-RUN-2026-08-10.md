## sdk79 — the hang is the most important finding here

The log dead-looped on three validation errors, cycling forever with no progress:

```
Validation error: split child <sid> already adopted
Validation error: Invalid tx0 output pubkey
Validation error: tx0 output is spent or not confirmed
```

"tx0 output is spent or not confirmed" repeating suggests a poll loop waiting for a confirmation
that never arrives — consistent with either (a) an electrs/bitcoind indexing stall (bitcoind runs
under `qemu-x86_64` emulation on this ARM host, which is slow), or (b) a genuine watchtower test
with an **unbounded retry and no timeout**. Either way it is a defect: a test must not be able to
wedge the whole suite for 11 hours. **Fix regardless of root cause: bound the retry with a
deadline** so it FAILs with the last error instead of hanging. Root-cause (a) vs (b) needs a
re-run in isolation: `RGB_E2E`-vs-`SDK_E2E` is not the issue (79 is a real SDK test).
